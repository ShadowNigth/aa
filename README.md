# Bloque

Un pequeño sandbox 3D voxel inspirado en los juegos de construcción: explora una isla, rompe bloques y construye tu propio paisaje.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Controles

- **Arrastrar con el ratón:** girar la cámara.
- **Rueda del ratón:** acercar o alejar.
- **Clic:** romper un bloque.
- **Mayús + clic:** colocar el bloque seleccionado.
- **1–8:** elegir un bloque de la barra rápida.
- **I:** abrir el inventario; **Esc** lo cierra.

Los cambios se guardan automáticamente en este navegador. **Guardar mundo** descarga una copia `.json`; abre el inventario y elige **Importar un mundo guardado** para restaurarla.

## Compilar

```bash
npm run build
```
